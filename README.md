# Too Much Input: sensory log

A small offline web app for logging sensory overload and spotting patterns. Made by @thatgirlwiththegreyhair to go with the Too Much Input guide.

Everything a person logs stays in their own browser on their own device. There are no accounts and nothing is sent anywhere.

Live at https://thatgirlwiththegreyhair.github.io/too-much-input/
